1 Créer votre compte enseignant

  1. Ouvrez l'application dans le navigateur.

  2. Cliquez sur le bouton 👨‍🏫 Espace enseignant (barre d'outils en haut).

  3. Sur l'écran de connexion, cliquez sur « Créer un compte enseignant ».

  4. Remplissez : Nom affiché (ex. M. Dupont), Identifiant (ex. mdupont), Mot de passe + confirmation.

  5. Cliquez sur « Créer mon compte ».

✅ Un code établissement unique du type ENS-A3F7 est généré automatiquement. C'est le code à donner à vos élèves. Notez-le ou copiez-le.

  1. Cliquez sur « Continuer vers mon espace » pour accéder à votre tableau de bord.

2 Découvrir votre espace

Une fois connecté, vous disposez de deux onglets :

OngletContenu
📋 Mes sessionsToutes les sessions de vos élèves, groupées par établissement
🏫 Mon établissementVotre code ENS, vos établissements déclarés, changement de mot de passe

3 Déclarer vos établissements

  1. Allez dans l'onglet 🏫 Mon établissement.

  2. Dans « Mes établissements déclarés », saisissez le nom (ex. Collège Montaigne).

  3. Cliquez sur ➕ Ajouter. Répétez pour chaque établissement.

Les élèves verront votre liste et sélectionneront le bon lors de la création de session. Vous pouvez ajouter ou supprimer des établissements à tout moment.

4 Partager votre code établissement

  1. Allez dans l'onglet 🏫 Mon établissement.

  2. Votre code est affiché en grand — cliquez sur 📋 Copier.

  3. Communiquez ce code à vos élèves (au tableau, dans l'ENT, par message…).

⚠️ Sans ce code, les sessions des élèves n'apparaîtront pas dans votre espace. Les élèves peuvent saisir le code avec ou sans le préfixe ENS-.

5 Côté élève — Créer une session

Étape 1 — Ouvrir la modal de collaboration

Cliquer sur le bouton 👥 Session dans la barre d'outils en haut.

Étape 2 — Remplir le formulaire

  • Ton prénom : prénom de l'élève (visible sur ses écrans)
  • Nom du projet : ex. Application météo
  • Classe : ex. 4C, 3B

Cliquer sur 🚀 Créer une session.

Étape 3 — Saisir le code établissement

L'application demande le code fourni par le professeur (ex. ENS-A3F7). Saisir le code → Valider → sélectionner l'établissement dans la liste → Confirmer.

Étape 4 — Noter le code PIN

Après validation, l'application affiche :

  • Un code de session à 6 caractères (ex. AB3X7K) → à partager avec les camarades
  • Un code PIN à 4 chiffres → indispensable pour retrouver son travail à la séance suivante
🔑 Important : Sur les ordinateurs partagés qui effacent les données entre séances, le PIN est la seule façon de récupérer son travail. Demandez à chaque élève de noter son prénom + son PIN.

6 Côté élève — Rejoindre une session existante

Première connexion à un projet de groupe

  1. Cliquer sur 👥 Session → « Rejoindre une session »

  2. Saisir le code à 6 caractères donné par le créateur du projet

  3. Entrer son prénom → cliquer Rejoindre comme nouveau membre

  4. Noter son PIN qui s'affiche

Reconnexion séance suivante

  1. Cliquer sur 👥 Session → saisir le code à 6 caractères

  2. Sélectionner son prénom dans la liste → saisir son PIN

  3. Les écrans et le travail précédent se rechargent automatiquement

8 Côté élève — Collaborer en temps réel

  • Les écrans des camarades apparaissent dans le panneau gauche (étiquette verte avec prénom) — consultation en lecture seule
  • Le 💬 chat (bas droite) permet d'échanger des messages en temps réel
  • Le professeur peut envoyer des messages depuis son espace (badge PROF visible par tous)

Appliquer un arrière-plan à plusieurs écrans (créateur uniquement)

  1. Cliquer sur 🎨 Appliquer arrière-plan à… dans le panneau des écrans

  2. Cocher les écrans souhaités (les siens + ceux des camarades) → Tout cocher si besoin

  3. Cliquer Valider — les autres membres reçoivent une notification pour accepter ou refuser

9 Suivre le travail depuis votre espace

Les sessions sont groupées par établissement (accordéons). Cliquer sur 👁️ Détails pour accéder à :

OngletContenu
👤 MembresAperçu fidèle des écrans, PIN de chaque élève, export HTML individuel, retirer un membre
💬 MessagerieHistorique des messages, envoi d'un message PROF visible par tous les élèves

12 Questions fréquentes

Un élève ne retrouve plus son travail

Bouton 👥 Session → entrer le code à 6 caractères → sélectionner son prénom → saisir son PIN. Le PIN est visible dans votre espace (onglet Membres).

La session d'un élève n'apparaît pas dans mon espace

Il n'a pas saisi votre code établissement lors de la création. Vérifiez qu'il utilise bien votre code ENS-XXXX.

Comment travailler à plusieurs sur le même projet ?

Un élève crée la session et partage le code à 6 caractères. Les autres cliquent sur Rejoindre et entrent ce code.

Puis-je bloquer une session pendant l'évaluation ?

Oui : 🔒 Bloquer dans le détail de la session. Les élèves ne peuvent plus accéder. Cliquez sur 🔓 Débloquer pour rouvrir.
