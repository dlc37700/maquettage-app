# 📱 MaquetApp — Guide de l'enseignant

Bienvenue ! **MaquetApp** est une application qui permet à vos élèves de créer des **maquettes d'applications mobiles** (écrans, boutons, images, barres de navigation…) directement dans le navigateur, sans rien installer.

Ce guide vous explique comment **créer votre compte**, **gérer vos classes** et **suivre le travail de vos élèves**.

---

## 1. Créer votre compte enseignant

Chaque enseignant possède son propre espace, séparé de celui des autres. Vos élèves et vos sessions ne sont visibles que par vous.

1. Ouvrez l'application dans le navigateur.
2. Cliquez sur **👨‍🏫 Espace enseignant** (dans la barre d'outils ou le menu).
3. Sur l'écran de connexion, cliquez sur **« Créer un compte enseignant »**.
4. Remplissez :
   - **Nom affiché** : votre nom (ex. *M. Dupont*)
   - **Identifiant (login)** : ce que vous taperez pour vous connecter (ex. *mdupont*)
   - **Mot de passe** + **confirmation**
5. Cliquez sur **« Créer mon compte »**.

> ✅ Un **code établissement unique** est alors généré, du type **`ENS-A3F7`**.
> **C'est le code que vous donnerez à vos élèves.** Notez-le bien (vous le retrouverez aussi dans votre espace).

6. Cliquez sur **« Continuer vers mon espace »** : vous êtes connecté.

---

## 2. Déclarer vos établissements

Avant que vos élèves ne créent des sessions, déclarez le ou les établissements où vous enseignez.

1. Dans votre espace, ouvrez l'onglet **🏫 Mon établissement**.
2. Dans **« Mes établissements déclarés »**, saisissez le nom (ex. *Collège Montaigne*) puis cliquez sur **« Ajouter »**.
3. Répétez pour chaque établissement.

> Vous pouvez en ajouter ou en supprimer à tout moment.

---

## 3. Partager votre code établissement

Vos élèves auront besoin de votre **code établissement** (`ENS-XXXX`) pour relier leurs sessions à votre compte.

1. Onglet **🏫 Mon établissement**.
2. Votre code est affiché en grand : cliquez sur **📋 Copier**.
3. Communiquez ce code à vos élèves (au tableau, dans l'ENT, sur une feuille…).

> ⚠️ Sans ce code, le travail des élèves **n'apparaîtra pas** dans votre espace.

---

## 4. Côté élève — Créer une session

Voici ce que feront vos élèves (à expliquer en classe) :

1. Cliquer sur **« Créer une session »**.
2. Saisir : leur **prénom**, le **nom du projet**, le **nom de la classe** et l'**établissement**.
3. Saisir le **code établissement** que vous leur avez donné (ex. `ENS-A3F7`).
4. Après validation, choisir le **bon établissement** dans la liste qui apparaît.
5. L'application affiche alors :
   - un **code de session à 6 caractères** (à partager avec les camarades qui rejoignent le même projet)
   - un **code PIN à 4 chiffres** *(important : voir l'encadré ci-dessous)*

> 🔑 **Le code PIN est essentiel sur les ordinateurs du collège.** Comme les ordinateurs partagés effacent souvent les données entre deux séances, le PIN est la seule façon pour un élève de **retrouver son travail** à la séance suivante. Demandez à vos élèves de **noter leur prénom + leur PIN**.

### Rejoindre une session existante
Un élève qui rejoint le projet d'un camarade clique sur **« Rejoindre »**, saisit le **code de session à 6 caractères**, puis sélectionne son prénom (et son PIN s'il revient).

---

## 5. Suivre le travail de vos élèves

Dans l'onglet **📋 Mes sessions**, vous voyez **toutes les sessions reliées à votre code établissement**.

Chaque session affiche :
- son **code** et son **statut** (🟢 Active / ⚫ Inactive / 🔴 Bloquée)
- la **classe**, la **date de création**, et la **liste des élèves**

Cliquez sur **👁️ Détails** pour ouvrir une session. Vous y trouverez deux onglets :

### Onglet 👤 Membres
- Aperçu miniature des **écrans de chaque élève**
- Possibilité d'**exporter** le travail d'un élève (fichier JSON)
- Possibilité de **retirer un membre** de la session

### Onglet 💬 Messagerie
- L'**historique des messages** échangés dans la session
- Une zone pour **envoyer un message en tant que professeur** : tapez votre texte (ex. *« Merci d'éviter ce genre de message »*) et cliquez sur **📨 Envoyer**. Le message apparaît immédiatement chez **tous les élèves** de la session, avec un badge **PROF**.

---

## 6. Gérer les sessions

Depuis la liste ou le détail d'une session :

| Action | Effet |
|---|---|
| **🔒 Bloquer** | Empêche tout accès à la session (les élèves ne peuvent plus y entrer). Réversible avec **🔓 Débloquer**. |
| **📋 Copier code** | Copie le code de session. |
| **🗑️ Supprimer** | Supprime **définitivement** la session et toutes ses données. ⚠️ Irréversible. |

> 💡 Une session devient **inactive** automatiquement quand tous les élèves l'ont quittée.

---

## 7. Gérer votre compte

Onglet **🏫 Mon établissement**, section **« Changer mon mot de passe »** :
1. Saisissez votre **ancien mot de passe**.
2. Saisissez le **nouveau** (au moins 4 caractères).
3. Validez.

Pour vous **déconnecter**, utilisez le bouton de déconnexion en haut de votre espace.

---

## 8. Questions fréquentes

**Un élève a perdu son travail / ne le retrouve plus.**
→ A-t-il bien noté son **PIN** ? À la reconnexion, il doit cliquer sur **Rejoindre**, entrer le code de session, sélectionner son prénom et saisir son PIN.

**Le travail d'un élève n'apparaît pas dans mon espace.**
→ Vérifiez qu'il a bien saisi **votre code établissement** au moment de créer sa session. Sans ce code, la session n'est rattachée à aucun enseignant.

**Plusieurs classes / établissements ?**
→ Déclarez tous vos établissements (étape 2). Les élèves choisiront le bon dans la liste. Le **nom de la classe** saisi par l'élève vous permet de les distinguer.

**Puis-je travailler à plusieurs sur le même projet ?**
→ Oui : un élève crée la session et partage le **code à 6 caractères** ; les autres le rejoignent. Chacun voit les écrans des autres (en lecture seule) et travaille sur les siens.
